TL;DR

  • Replace the per-frame full-scene mesh/flatten/upload (App::OnRender, App.cpp:1311-1758) and the broken ChunkMeshCache with per-chunk meshDirty meshes in persistent per-chunk SDL_GPUBuffers, one draw per visible chunk with a chunk offset in the vertex uniform.
  • Mesher emits chunk-local Vertex3D for exposed faces only; unloaded neighbors solid on X/Z, air on ±Y. Edits go through new ChunkManager::setBlock/removeBlock, dirtying the chunk and boundary neighbors.
  • Stages: (1) worldgen fix + FrameProfiler + benchmark path + baseline, (2) dirty flag + mesher, (3) GPU store + shader/spv rebuild, (4) neighbor culling, (5) delete cache/LOD.
  • Developer-facing only: key B toggles a benchmark orbit, SDL_Log reports avg/p95/max. No tests, no build-config change.

Technical approach

Worldgen or edit sets meshDirty (chunk plus boundary neighbors). Each frame every dirty chunk is remeshed into chunk-local Vertex3D, uploaded through one pooled transfer buffer in one copy pass into its persistent buffer, and drawn with a chunk offset uniform.

OnRender order: acquire command buffer, frustum and view-projection, Build (remesh), Upload, Acquire swapchain, Record (bind once, per-chunk cull, push uniform, bind, draw), end pass, Submit. setBlock must not hold chunk references across emplace_back. Stage 2 uses a transitional per-chunk CPU cache flattened into the old scene buffer, removed in stage 3.

Success criteria

  • Clean frames: zero chunks remeshed, zero bytes uploaded; camera motion alone triggers none.
  • Edit remeshes only the edited chunk plus the boundary neighbor; no stale or missing geometry.
  • Hold-pose image identical to baseline after stages 2 and 3; after stage 4 differs only on the open outer X/Z sides.
  • Vertices-drawn average drops after stage 4 with no visible border holes.
  • Avg and p95 frame time improve versus the stage 1 baseline under the same build config and present mode.
  • No buffer overflow or validation error on growth; Quit releases all chunk buffers.
  • 4 distinct chunks, worldChunks.size() == chunkMap.size(); no cache/LOD/std::execution code left; vertex.spv matches vertex.glsl.
