# Gap Analysis: Dirty-Flag Per-Chunk GPU Meshes (SDL_3DR)

## TL;DR
- Gap: per-frame full-scene mesh/flatten/upload with a broken Face cache, versus dirty-flag per-chunk meshes on persistent GPU buffers, plus profiler, neighbor culling and worldgen fix.
- Modifies existing code (App::OnRender, Chunk, shader) and adds new files (FrameProfiler, mesher / GPU store). Not UI-heavy; no CRUD entity (single E-key remove mutation).
- Risk: Medium. Effort: High (dense OnRender rewrite, shader rebuild, GPU ownership, no tests).
- New findings: worldgen fix is more than one typo (inclusive `PositionInBounds`, noise ignores chunk offset); literal "unloaded = solid" also hides terrain top faces (needs a vertical-axis decision).

## Key Decisions
- Characteristics: modifies_existing_code=yes, creates_new_entities=yes (profiler, mesh store), involves_data_operations=no, ui_heavy=no, has_reproducible_defect=no (worldgen z bug is an in-scope correctness fix inside a refactor).
- Change type: modificative + additive. Compatibility: flexible (single-dev prototype, no persisted formats, standards forbid backward compat).
- GPU handles kept out of `Chunk` (App-side store keyed by Int3), because `Chunk` is copied/moved in `worldChunks`.

- No tests, unknown build type: verification by profiler, screenshots, optional device debug.

## Gaps Identified

### Missing Features
- **FrameProfiler**: none exists (SLog timing compiled out by `debugLevel=0`; `totalFPS/numFPS` uninitialised App.h:147-148, div-by-zero risk at Quit:725). Needs `SDL_GetPerformanceCounter` stage scopes, ring buffer, avg/p95/max via unconditional `SDL_Log`, and a key-toggled fixed camera path (unused key needed; ESC/W/A/S/D/SPACE/SHIFT/F/E taken, App.cpp:573-660).
- **Per-chunk GPU mesh store**: absent; single scene buffer sized once (`canCreateVertexBufferEveryFrame=false`, App.cpp:42), overflow risk.
- **Neighbor lookup helper** on `ChunkManager` (`chunkMap` is `std::map<Int3,size_t>`, no accessor).
- **Chunk offset in vertex shader**: UBO is mat4 only (vertex.glsl 63-65); `vertex.spv` is committed and regenerated by glslang at configure.
- **`meshDirty`** flag and dirty hooks.

### Incomplete / Broken Features
- `chunkFaceCulling` (constexpr false, App.cpp:41; 1443-1478) is not real culling; replaced wholesale.
- `ChunkMeshCache`/`LODDBLock`: inverted, never invalidated, camera-dependent; deleted (Chunk.h:6,25-26,77-81; CMakeLists.txt:32).
- Chunk frustum AABB (1367-1380) uses atPosition..+N while blocks are centred on integers; needs a -0.5 offset.

### Behavioral Changes Needed
- Meshing: per-frame world-space Faces -> on-demand chunk-local Vertex3D; preserve winding/normals per Face.cpp face order.
- UVs: `chooseFaceUV` depends on vertex position; compute from world position (chunk origin + local), so the mesher needs the chunk origin. Sampler is REPEAT (App.cpp:1070-1072), so this is a safety choice, not a necessity.
- Draw: one draw -> one draw per visible non-empty chunk with a per-draw vertex uniform push; `num_uniform_buffers=1` kept (App.cpp:264) using `{mat4; vec4}`.
- Upload: per-frame transfer buffer + WaitForGPUIdle regrow -> pooled transfer buffer, one copy pass, per-chunk capacity/regrow, immediate `SDL_ReleaseGPUBuffer` (SDL defers internally).

## Worldgen Bug Scope (item 4)
- App.cpp:1192 uses `atPos.y` as z, so chunks for (0,0,16)/(16,0,16) are created at z=0; `chunkMap.insert` silently drops duplicate keys while `worldChunks` keeps them (map and vector disagree; neighbor lookup would hit wrong chunks).
- Inclusive `Chunk::PositionInBounds` (Chunk.h:89-91, `<= atPosition + N`) is a latent bug; must not be used for cross-chunk resolution.
- Noise ignores chunk offset (out of scope): four columns with identical terrain.
- `push_back(chunk)` copies at 1213-1216 and `emplace_back` reallocation are why handles stay outside `Chunk`.

## Data Lifecycle Analysis (light)
Entity: block in chunk. CREATE = worldgen `tryInsert` (new chunks default dirty). READ = mesher. UPDATE = none (add path commented out, 671-698). DELETE = E-key `reset()` (659-660), hook after it. Mutable `operator[]`/`tryGet` cannot self-mark dirty (bypass risk, see D2). Chunk creation on E-key (648-652) must dirty new chunk and existing neighbors. No orphaned operations; profiler has backend (timers), output (SDL_Log, independent of `debugLevel`) and access (key toggle).

## Issues Requiring Decisions

### Critical
1. **D1 Vertical boundary under "unloaded = solid"** (`policy-vertical-boundary`): applied literally on all 6 sides, terrain top faces (nothing loaded above y=0 chunk) and bottom faces vanish, making terrain invisible from above.
   - Options: (A) solid for X/Z only, air for +Y/-Y (recommended); (B) solid on all 6 sides literally.
   - Recommendation: A.
2. **D2 Dirty-marking bypass** (`dirty-bypass`): non-const `operator[]`/`tryGet` hand out mutable refs.
   - Options: (A) add `setBlock`/`removeBlock` that mark dirty, route E-key through it, mesher uses const reads (recommended); (B) restrict/remove non-const accessors; (C) mark dirty in every non-const accessor.
   - Recommendation: A.

### Important
3. **D3 Chunk creation on E-key** (`chunk-create-on-edit`): options (A) keep lazy creation, dirty new chunk + neighbors (default); (B) reserve `worldChunks` capacity up front.
4. **D4 Benchmark conditions** (`benchmark-conditions`): present mode is MAILBOX if supported else VSYNC (App.cpp:233-239), viewport fixed 1920x1080. Options: (A) log present mode and build info in the report, force nothing (default); (B) force a non-vsync mode during benchmark.
5. **D5 `PositionInBounds` bound** (`bounds-fix`): options (A) change to exclusive `<` (default); (B) leave and avoid it in neighbor code.
6. **D6 Remesh threading** (`remesh-threading`): options (A) single-threaded in-frame remesh (default); (B) `std::execution::par` per dirty chunk.
7. **D7 Cleanup breadth** (`cleanup-scope`): options (A) delete only code this task replaces plus dead lambdas at 1334-1353 (default); (B) also unused `GetFaceLineCallVerticies` and commented worldgen block 1123-1156.

## Recommendations
- Stage order: worldgen z fix and profiler/baseline first (baseline must use the final scene) -> `meshDirty` + neighbor helper + chunk-local mesher with world-position UVs -> per-chunk GPU store + shader/spv rebuild -> neighbor culling + dirtying -> delete cache/LOD.
- Add `static_assert(sizeof(Vertex3D)==60)`; keep vertex layout.
- New source files go in the CMakeLists source list (not a build-config change); remove ChunkCache.h.
